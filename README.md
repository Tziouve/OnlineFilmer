# 🎬 OnlineFilmer — Movie Discovery Web App

OnlineFilmer is a movie browsing web application built with **PHP, MySQL, JavaScript, and jQuery**.
Users can create accounts, log in securely, explore movies by genre, and discover popular, top‑rated, and upcoming titles through real‑time API integration.

Selecting a movie opens a dedicated details page displaying its poster, plot summary, and key information.

> 👤 Built as a personal project to practice full‑stack web development and client–server architecture.

## ▶️ How to Run

### Requirements

* XAMPP / WAMP / MAMP (or any PHP server environment)
* PHP 7+
* MySQL
* Web browser

### Running the Project

1. Clone the repository
2. Open the project and locate the inner folder named `OnlineFilmer/`
3. Move **that folder** into your server directory (e.g., `htdocs` for XAMPP)
4. Start Apache and MySQL from your server control panel
5. Create a database named:

   ```
   OnlineFilmer
   ```
6. Import **both** SQL files from the `/sql/` folder into that database
7. Open in your browser:

   ```
   http://localhost/OnlineFilmer/php/index.php
   ```
